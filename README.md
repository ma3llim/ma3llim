### 🤖 AI Knowledge & Document Assistant

An AI-powered document assistant built with **Java, Spring Boot, Spring AI, and React**, enabling users to interact with their documents through conversational AI.

**Highlights**

- Spring AI + LLM integration
- Retrieval-Augmented Generation (RAG)
- Document extraction and processing
- Token-based document chunking
- Embeddings + pgvector similarity search
- Top-5 retrieval + Top-3 reranking
- Prompt engineering
- Conversation context and memory
- AI guardrails
- Structured AI responses
- WebSocket-based AI response streaming
- AWS SQS + Dead-Letter Queue for asynchronous processing
- Cloudflare R2 document storage
- PostgreSQL + pgvector
- Docker-based deployment

🔗 **[Live Demo](https://ai.mohdsameer.info/)**
